# Polynomial Multiplication

A Python solution that multiplies two polynomials by multiplying every pair of coefficients and adding terms with the same power.

[polynomial_multiplication.py](polynomial_multiplication.py) takes two nonempty coefficient lists of equal length, ordered from the constant term upward.

For `[5, 2, 3]` and `[2, 1, 5]`, representing `5 + 2x + 3x^2` and `2 + x + 5x^2`, the result is **[10, 9, 33, 13, 15]**.
